# ⚡ Como executar

Clone o repositório:

```bash
git clone https://github.com/LucasMacedoDev/Portifolio_Lucas_Macedo.git
```

Entre na pasta:

```bash
cd Portifolio_Lucas_Macedo
```

Abra o arquivo:

```
index.html
```

Não é necessário instalar dependências.
